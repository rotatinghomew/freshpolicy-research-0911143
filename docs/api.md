# 资料服务接口

服务只在本机提供 JSON，响应编码为 UTF-8。查询接口不修改资料。

| 方法和路径 | 当前行为 |
| --- | --- |
| `GET /health` | 数据指纹和存活状态 |
| `GET /tables` | 表、字段类型和记录数 |
| `GET /tables/{name}?offset=0&limit=50` | 原始资料分页；偏移非负，每页一至五百行 |
| `GET /view` | 当前领域经营资料摘要 |
| `GET /profiles` | 数值字段的观察数、缺失数、中位数及绝对中位差 |
| `POST /cases` | 保存研究备注和当前完整资料副本；返回新记录 |
| `GET /cases` | 研究记录索引 |
| `GET /cases/{id}` | 校验完整性并回读记录 |
| `POST /trials` | 运行补货策略试算并保存完整规格与报告；返回新记录 |
| `GET /trials` | 试算记录索引 |
| `GET /trials/{id}` | 校验完整性并回读试算规格与报告 |
| `GET /trials/{id}/trace?rule=名称&scenario=序号` | 按保存规格确定性重算该规则在该情景的逐日逐批追溯 |

创建研究备注的字段为 `label`、`options` 和 `notes`，分别是名称、参数对象与说明文字。名称一至一百二十字，后两项可省略。不接受其他字段，不允许覆盖旧记录。记录 ID 由服务生成。资料指纹由原始数据和结构共同形成，不表示计算结果的统计可信度。

试算请求字段均可省略，省略时按下述默认：

| 字段 | 默认与约束 |
| --- | --- |
| `label` | 试算名称，不超过一百二十字 |
| `fit_start` / `fit_end` | 拟合窗，默认需求资料前七成日期 |
| `eval_start` / `eval_end` | 评估窗（历史留时段），默认其余日期；需满足 拟合止 < 评估起 |
| `scenarios` | 抽样情景数，四至二百，默认 32 |
| `seed` | 非负整数种子，默认 20260801；同规格结果完全一致 |
| `warmup_days` | 评估窗前的预热天数，零至三十，默认 7；预热期不计指标 |
| `rules` | 候选规则列表，默认 `sold_average`、`intent_average`、`order_up_to`；每项含 `name` 与可选 `params` |
| `baseline` | 配对差异的基线规则名，默认列表第一项 |
| `demand_scale_band` | 需求假设区间 [下限, 上限]，默认 [0.85, 1.15] |
| `stress` | 是否附加极端供货情景，默认 true |

候选规则：`sold_average`（按近期销量均值订货，基线）、`intent_average`（按近期已知意向均值订货，意向全缺失时退回销量均值）、`order_up_to`（订货至目标水平，参数 `window`、`lead_days`、`safety`）、`none`（不订货对照）。规则参数只接受各自字段，越界或未知字段返回 400。

试算报告含假设与口径声明、需求与供货证据、情景索引、抽样情景下各规则的联合指标（缺货、满足率、损耗、经营贡献及成本明细）与对基线的配对差异区间、历史回放与极端情景的单独结果、需求假设区间下的敏感性。追溯接口的 `scenario` 为报告 `scenario_index` 中的序号（0 为历史回放），`rule` 缺省为基线规则。试算记录与研究备注同样不可覆盖、带完整性校验；试算只保存规格与报告，追溯在读取时按规格确定性重算。

源表未找到或记录 ID 无效返回 404；字段或分页无效返回 400。默认监听 127.0.0.1:8080。服务当前提供资料浏览、数值探索、研究备注和策略试算，不将保存备注或试算视为已经完成经营分析，也不自动执行订货。

源表未找到或记录 ID 无效返回 404；字段或分页无效返回 400。默认监听 127.0.0.1:8080。服务当前提供资料浏览、数值探索和研究备注，不将保存备注视为已经完成经营分析。
