# 策略试算口径

试算在同一组可复现情景中比较候选补货规则，只用于经营研究，不生成也不执行任何实际订货。本文件约定模拟次序、记账口径、情景构造与信息纪律；接口字段见 `docs/api.md`。

## 每日次序与批次流转

每日按资料约定依次发生：上午到货、午间需求、下午订货、零点过期结转。

- 到货：订货日在 D 的订单，期望到货日为 D+1，实际到货日 = D+1 + 该供应商日共同延误。同一供应商日的全部品种共享同一延误与容量，不互相独立。当日订货总量超过该供应商日容量时按品种订量比例压缩。
- 需求：情景给出每个品种的意向量。实际售出受库存限制，逐批先到期先出（FEFO），批次可部分消耗。缺货 = 意向 − 售出，绝不用销量反推意向。
- 退货：按情景退货率从售出中产生，一律报废，不回到可售库存。
- 订货：规则在下午截止点下单，只能看到当时可知信息（见下节）。有订量的品种计一次订货费。
- 零点：到 expires_at 即不可售，过期批次计入损耗；其余批次跨日结转并按公斤计持有费。

## 记账口径（探索性浮点）

- 收入 =（售出 − 退货）× 挂牌价；退货视为退款且货物报废。
- 采购成本在到货日按 到货量 × 成本 确认；订货费在下单日确认；持有费按跨日结转公斤计；过期与退货各按公斤计处置费。
- 经营贡献 = 收入 − 采购成本 − 持有费 − 处置费 − 订货费。
- 期末在库按成本单列（terminal_inventory_value），不计入贡献也不视为损耗；期末未达订单只计订货费（terminal_outstanding_kg 列示）。
- 金额在试算中为浮点探索口径，正式对账仍以原始十进制字段为准。

## 情景构造

拟合只使用拟合窗（留时段之前）的资料，评估窗为历史留时段。四类情景组成一次试算：

1. 历史回放（1 条）：评估窗内使用真实意向（缺失日按拟合窗中位数填补并标记为不可见）、真实供应商日冲击与真实退货率；超出资料覆盖的供应商日回退到拟合窗中位数。
2. 抽样情景（N 条，种子可复现）：意向按品种从拟合窗已知意向经验分布独立抽样；退货率同理；供应商日（延误、容量）整行重抽样以保留共同冲击；剩余保质期按品类经验分布抽样。意向观测缺失按拟合窗整日缺失率模拟，缺失日规则看不到意向。
3. 极端延误与缩量（1 条）：每日延误取拟合窗最大、容量取最小、保质期取最短，需求取拟合窗中位数。
4. 连续三日断供（1 条）：评估窗中段连续三个订货日容量为零，其余取中位数。

极端情景单独报告，不并入抽样平均。情景在规则运行前生成完毕，同一组情景供全部候选规则复用（共同随机数），差异按情景配对。

## 信息纪律

规则每次决策只收到：当前日期、当前在库批次（含到期日）、在途订单、截至当日的历史记录（拟合窗真实记录与已发生的模拟事件，含当日已发生的需求）。规则看不到后续真实或模拟的到货、延误与需求。评估窗内的历史是模拟自身产生的，不是评估窗真实资料。

## 指标与区间

抽样情景下按规则汇总：缺货公斤、满足率（售出/意向）、损耗公斤（过期 + 退货报废）、经营贡献及收入、各项成本、期末在库。规则两两与基线规则按情景配对求差，报告均值、95% t 区间、极差与差值为正的情景占比。回放与极端情景为单一路径，只报告与基线的差值，不给区间。

## 需求证据与假设范围

拟合窗内意向缺失日不按销量回填；抽样只来自已知意向分布，这等价于假设缺失意向与已知意向同分布。报告的证据部分给出各品种已知/缺失天数；敏感性部分把全部抽样意向按需求假设区间（默认 0.85～1.15 倍）缩放后重跑比较，给出各规则贡献与缺货的移动及最优规则是否变化。跨品种需求独立抽样，未建模品种间相关。容量视为当日可交付上限；拟合窗内存在历史到货超过名义容量的供应商日，该口径偏保守，具体天数在报告假设中列明。

## 追溯

`GET /trials/{id}/trace` 按保存的规格确定性重算某条规则在某个情景下的逐日记录：每日每品种的期初批次、到货、意向/售出/缺货/退货、当日订单、过期批次、期末批次与在库价值，以及当日收入、采购、持有、处置、订货费与贡献。追溯用于理解收益与风险的取舍，不触发任何订货动作。
